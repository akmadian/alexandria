# The v0 cut

**Status: RATIFIED** (v0 round, 2026-09-09). This cuts *features*, not
foundations: the data model carries the full settled noun shape from day one
(assets permit zero files; volumes/folders/files fully modeled) — but kind-specific
modeling for deferred features (notes, web pages, markers) waits until they're built.

## In

- Import: in-place only; directory / single / multiple files; universal import
  floor; embedded-preview-first; automatic file→asset grouping via grouping
  rules (RAW+JPEG the canonical case); deterministic per-stage progress;
  import-critical vs deferrable split
- Grid: sortable, multi-select incl. discontiguous
- Loupe: fit / fill / 100% zoom; lights-out mode; full-screen mode
- Judgments: rating, pick/reject; durably committed per gesture; undo/redo
- Stacks: manual stack and dissolve
- Filtering: the query workhorse — predicates over judgments, filenames,
  keywords, metadata fields
- Keywords: assign / remove / hierarchy, in-catalog only (no XMP write-back in v0)
- Collections: manual (with manual ordering) and smart
- Folders: browse, rescan on demand, cheap relocation repair, graceful
  "missing" state
- Volumes: identity, online/offline; browse/filter/judge offline volumes from
  the cached index and previews
- Disk verbs: remove-from-catalog vs delete-to-Trash (verbs, not a prescribed
  UI shape); delete-all-rejects
- Inspector: fixed layout, shows metadata
- Keybindings: core set (designed knowing full customization comes later)
- Catalogs: multiple on disk; siloed windows; in-window switch (close, verify
  not locked, swap, spin up); open from local paths only
- Cross-cutting NFRs: UI never blocks, crash-safe judgments, interrupted-work
  recovery, citizenship basics

## Trailing (post-v0; sequence undecided)

XMP write-back · text search (v1) · FTS + semantic search · export presets and
finishing · color labels · AI tagging/culling · duplicate detection · faces ·
LrC migration · catalog backup verb · batch rename / move-reorganize · compare
view · video trim · external-editor round trip · markers · notes / web pages ·
inspector per-kind configurability · full keybinding customization ·
multi-catalog conveniences beyond switching
