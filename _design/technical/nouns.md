# Nouns

Settled vocabulary with technical weight. One entry per noun; the round
that ratified it in parentheses.

- **record** — a thing stored in the catalog database; never "row", which
  is reserved for a grid row of items on screen. (CLAUDE.md, standing.)
- **facet** — one overlapping *nature* a file can have, as a section of
  its metadata: `visual`, `timing`, `capture`, `media`, `audio`,
  `authorship`, `location`. A kind is a combination of facets, not a
  struct; presence is evidence, decided by what the file testifies to,
  never by a kind lookup. Also the registry's `isRawCapture` ("rawness is
  a facet, never a kind") — same word, same idea: orthogonal natures over
  exclusive categories. (Metadata modeling round, 2026-09-17; see
  technical/metadata.md.)
